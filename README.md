# PS Cafe Manager — V6.2.0

إصدار **Owner & Branding Secure Foundation**.

## تشغيل التطبيق

ارفع محتويات هذه الحزمة إلى GitHub Pages في جذر المشروع. التطبيق يعمل محليًا بدون ربط سحابي ويحتفظ بمنطق الجلسات والفواتير الحالي دون تعديل.

## قاعدة بيانات صاحب النشاط

للتشغيل السحابي الحقيقي، يجب أن يكون مشروع Supabase تحت ملكية صاحب النشاط. استخدم ملف `SUPABASE_SETUP.sql` داخل SQL Editor في مشروعه، ثم اربط التطبيق من صفحة **إدارة النشاط** باستخدام:

- Project URL
- Publishable Key فقط، أو `anon` العام القديم إذا كان مشروعه يستخدمه
- Business ID الناتج من ملف الإعداد
- بريد وكلمة مرور حساب Supabase Auth المصرح به على هذا الجهاز؛ حساب Owner لجهاز المالك وحساب محدود لأجهزة العاملين

لا تُدخل Secret Key أو Service Role Key داخل التطبيق أو GitHub.

## الواجهة والصلاحيات

- صاحب النشاط: إدارة النشاط، المستخدمين، البيانات، الربط، النسخ الاحتياطي، الأدوات الفنية.
- المدير: التشغيل والأجهزة والمصروفات والتقارير دون إعدادات فنية أو مستخدمين.
- الكاشير: التشغيل والمشروبات والفواتير فقط.
- المشاهد: عرض محدود للتقارير والفواتير.

## الملفات الرئيسية

- `index.html` — التطبيق
- `manifest.json`, `sw.js` — PWA والتحديث
- `brand-avatar.png`, `icon-*.png` — الهوية الجديدة
- `SUPABASE_SETUP.sql` — إعداد قاعدة بيانات المالك المحمية
- `RELEASE_REPORT_AR.md` — ملخص التنفيذ
